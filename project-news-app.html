News App

A Flutter news application that helps users explore the latest headlines, browse news by category, and search for articles in English and Arabic. It retrieves news data through a REST API and presents articles in a clean, responsive mobile interface.

What it does

  • Retrieves the latest news headlines from a REST API.
  • Lets users browse articles through categories including Technology, Business, Travel and Entertainment.
  • Provides a dedicated search screen for finding articles by keyword.
  • Displays English and Arabic search results.
  • Shows article cards with titles, images, authors and publication dates when that information is available from the API.
  • Uses GoRouter to navigate between the home, search and search-results screens.
  • Uses Flutter ScreenUtil to support responsive sizing and consistent spacing on mobile screens.

API integration

The app fetches news headlines and search results from an external news API. Networking logic is separated into service files, keeping API communication apart from the UI. The API provider, available endpoints and authentication requirements depend on the configuration used by the project.

When setting up the project locally, configure the API key required by the selected provider and avoid committing private credentials to a public repository.

Code organization

The codebase is organized into shared Core resources and feature-specific directories. The home, search and search-results features contain their own related models, services and widgets where applicable. This structure keeps shared styling and routing separate from screen-specific functionality.
