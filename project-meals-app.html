Meals App

A Flutter meal application that lets users add and browse their own meals through a clean mobile interface. Each meal includes a title, image URL, rating, preparation time and description, with meal records saved locally using SQLite.

What it does

  • Introductory onboarding carousel with Next and Skip actions.
  • Remembers whether onboarding has been seen using SharedPreferences.
  • Displays saved meals in a two-column grid.
  • Adds a meal with a title, image URL, rating, preparation time and description.
  • Validates required fields in the Add Meal form.
  • Opens a dedicated details screen for each meal.
  • Stores meal records locally using SQLite, so saved meals remain available when the app is reopened.
  • Loads meal images from URLs and uses responsive sizing with Flutter ScreenUtil.

Local data

The app stores meal details on the device using sqflite. The current implementation uses a local table named `tasks` with fields for the meal title, rating, time, description and image URL. SharedPreferences stores the onboarding-seen state. Remote meal images require an internet connection to load.
