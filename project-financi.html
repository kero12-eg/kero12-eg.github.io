Financi

Finance app screens and interaction flows for authentication, dashboard metrics, cards, charts and profile views, built with responsive layouts, navigation, charts and carousels.

Back to all projectsGitHub repository
Scope
UI only, static demo data
Platform
Android and iOS
Navigation
GoRouter, 8 routes
Design size
375 × 812

What it does

  • Authentication screens: login, register, forgot password, verification code, new password and a success screen.
  • Dashboard with a card carousel and Send Money and Pay The Bill actions.
  • Statistics screen with a January–May bar chart for income and outcome.
  • All cards and profile screens, with responsive layouts and navigation between them.

Implementation notes

  • There is no backend: the data shown is static demo data.
  • Routes are declared with go_router (8 routes); screens are sized from a 375 × 812 design with flutter_screenutil.
  • The Add tab in the bottom bar is a placeholder, so it does not appear in the screenshots.
